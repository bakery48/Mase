# マジック・メイズ モバイル 🧙⛏️🏹⚔️

ボードゲーム **「マジック・メイズ（Magic Maze）」**（Kasper Lapp 作 / Sit Down! 2017）を、スマホのブラウザで遊べるようにしたファンメイドのWebアプリです。
インストール不要・ビルド不要。ホーム画面に追加すればアプリのように遊べます（PWA）。

▶ **今すぐ遊ぶ: https://bakery48.github.io/Mase/**
📖 **原作ルールの日本語解説: [RULES.md](RULES.md)**

## 原作はどんなゲーム？（調査メモ）

- **協力型・リアルタイム**（2〜8人、約15分）。全員で勝つか全員で負ける。
- 魔術師（紫）・ドワーフ（橙）・エルフ（緑）・バーバリアン（黄）の4人のヒーローが、ショッピングモール「マジック・メイズ」で装備を盗んで逃げ出す。
- 流れ
  1. モールを探索してタイルを広げる
  2. 4人全員を**自分の色のアイテムマス**に**同時に**乗せる → 盗んでアラーム発動
  3. 全員が**出口**から脱出すれば勝利
- **最大の特徴**: プレイヤーは特定のヒーローではなく**「アクション」を担当**する。
  「北へ移動」担当の人はどのヒーローでも北に動かせるが、他の方向には動かせない。
  アクションは 東西南北の移動 / 探索 / エスカレーター / ワープ（渦）。
- **砂時計**: 制限時間は3分。砂時計マスに乗ると砂時計をひっくり返せる（各マス1回）。0になったら負け。
- **会話禁止**: 開始時と砂時計をひっくり返した直後以外はしゃべれない。代わりに「なにかして！」コマを相手の前に置いて急かす。
- 移動はその方向に好きなだけまっすぐ進む（壁・他のヒーローは通れない）。
- 探索はヒーローが**自分の色の探索マス**にいる時だけ。ワープは自分の色の渦へ瞬間移動（アラーム後は不可）。

参考: [Board Game Arena のルール解説](https://en.doc.boardgamearena.com/Gamehelpmagicmaze) / [BoardGameGeek](https://boardgamegeek.com/boardgame/209778/magic-maze) / [ルールブック（英語PDF）](https://world-of-board-games.com.sg/docs/Magic-Maze.pdf)

## このアプリでできること

| モード | 内容 |
| --- | --- |
| 🎮 ひとりで遊ぶ | 全アクションを1人で担当。時間との勝負（一時停止あり） |
| 🏠 部屋を作る / 🚪 部屋に入る | **各自のスマホで2〜4人オンライン協力**。4文字の部屋コードで参加。各スマホには自分の担当アクションだけが表示される、原作に近い遊び方 |

- ヒーローをタップ → 動ける場所に○が出るのでタップして移動
- 探索できるときは点線の枠をタップ
- ドラッグでスクロール、ピンチで拡大縮小、「🔭全体」で全体表示
- 「❗なにかして！」で相手のスマホを振動＆赤く光らせて急かせる
- 制限時間は かんたん5分 / ふつう3分 / むずかしい2分
- 役割分担: 2人 =「北・東・探索」「南・西・エスカレーター・ワープ」、3人・4人も自動で配分

### 原作との違い・簡略化
- タイルはオリジナルの14枚＋スタートタイル（シナリオ1相当：出口は全員共通の1つ）
- 壁はマス単位、オレンジの細い通路・監視カメラ・各キャラの特殊能力は未実装
- 会話のルールはプレイヤー同士の自主ルール（画面に「相談OK / 会話禁止」を表示）

## 遊び方（公開）

静的ファイルだけなので、どこにでも置けます。

### GitHub Pages
1. リポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** にする
2. `main` に push（このブランチをマージ）すると、テスト後に自動で公開されます
3. 表示されたURLをスマホで開き、「ホーム画面に追加」

### ローカルで確認
```sh
python3 -m http.server 8000
# → http://localhost:8000 を開く（同じWi-Fiのスマホからは http://<PCのIP>:8000）
```
※ オンライン対戦の通信は HTTPS（または localhost）が必要です。

## オンライン対戦のしくみ
- [PeerJS](https://peerjs.com/)（WebRTC）で端末同士を直接つなぎます。サーバー不要（接続の仲介に PeerJS の無料公開サーバーを使用）。
- ホストのスマホがゲームの状態と砂時計を管理し、他の端末に配信します。
- 一部のモバイル回線・企業ネットワークでは WebRTC が直接つながらない場合があります（その場合は同じWi-Fiで試してください）。
- 開発用に `?peerserver=127.0.0.1:9000` で自前の PeerServer を指定できます。

## 構成
```
index.html / style.css   画面
js/tiles.js              タイル定義（4x4、テキストで記述）
js/engine.js             ルール（移動・探索・ワープ・砂時計・勝敗）※描画と独立
js/render.js             キャンバス描画、パン・ズーム
js/net.js                オンライン通信（PeerJS）
js/app.js                画面制御・入力・ゲーム進行
vendor/peerjs.min.js     PeerJS 1.5.4（MIT）
test/engine.test.mjs     ルールのテスト＋ボットによる通しプレイ検証
```

テスト: `npm test`（Node.js 18+）
